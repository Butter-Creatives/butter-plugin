# Butter plugin

Install Butter into Claude Code or ChatGPT.

## Install

In ChatGPT: **Plugins → Add → Add a marketplace**

| Field | Value |
| --- | --- |
| Source | `https://github.com/Butter-Creatives/butter-plugin.git` |
| Git ref | `beta` |

Then open the **Plugins** tab, find **Butter**, and install it.

In Claude Code: `/plugin marketplace add https://github.com/Butter-Creatives/butter-plugin.git`

## This repo is generated

Everything here is written by `yarn plugin:release` in the Butter monorepo
(`modules/mcp`). Editing a `SKILL.md` here will be overwritten by the next release —
change `modules/mcp/src/playbooks/` instead.
